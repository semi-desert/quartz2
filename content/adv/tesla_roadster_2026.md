# 研究问题

1. 第二代 Roadster 怎么做到倒挂在垂直坡道上、又能腾空翻滚？
2. 做到这种程度需要多少知识？个人怎么入门火箭、机器人、无人机、飞机这一类研究？

# 事实（2026-10-16 发布会报道）

- 时间地点：当地时间 2026-10-15，得州麦格雷戈 SpaceX 测试场。
- 演示：车冲上 C 形巨型坡道，在垂直段中部和顶端倒挂悬停数秒；从顶端跃出，空中翻转，靠车底推进器减速后落地。
- 驾驶座坐着 Optimus 机器人，只是表演道具。特技由预设程序和远程操控完成，车内无人。
- 两套关键系统：
  - **风扇吸附系统**：多模式风扇 + 车底密封，抽走车底空气，产生下压力。官方称过弯横向加速度最高 2g，车静止时也能倒挂。
  - **冷气推进系统**（内部代号 A71，与 SpaceX 联合开发）：约 10 台冷气推进器 + 600 升压缩空气罐，不燃烧。
- 配置：性能版 / 推进版（Thrust）/ 火箭版（Rocket，单座、邀请制）。三电机四驱；0—60 mph 基础版约 1.9 s，推进版约 1 s。
- 计划 2028 年投产。带推进器的版本大概率不能合法上路，只用于封闭场地。

# 要点：原理

## 1. 倒挂靠气压差

- 车底四周用裙边密封，风扇把车底空气抽走，车底气压低于车顶。
- 车顶的大气压把车「按」在路面上。和吸盘是同一个原理。
- 数量级估算（**未验证**）：车重约 1.5 t，车底面积约 4 m²。需要压差 ≈ 1500 × 9.8 / 4 ≈ 3.7 kPa，只是大气压（101 kPa）的约 3.7%。所以工程上可行。
- 这个思路不新：
  - Chaparral 2J（1970，Can-Am 赛车）用过风扇吸附。
  - Brabham BT46B「风扇车」（1978，F1）只比赛一场就赢了，随后被禁用。

## 2. 腾空靠反冲（牛顿第三定律）

- 高压气体从喷嘴高速喷出，车受到反方向的推力。卫星、飞船的姿态控制用的就是冷气推进器。
- 车尾主推进器向后喷 → 加速；车底推进器向下喷 → 抬升、悬停；侧面推进器 → 稳定、旋转。
- 续航估算（**未验证**，假设气罐约 300 bar）：
  - 600 L 气罐约装 170—200 kg 空气。
  - 托住一辆车约需 20 kN 推力；冷气喷速约 700—800 m/s，每秒要喷掉约 25—30 kg 气。
  - 气只够约 **6—7 秒**。和视频里「悬停数秒再落地」一致。能飞一下，不能一直飞。

## 3. 真正的难点是控制

- 十几个推进器、风扇、三台电机要协同，每秒调整几百次，才能翻滚后稳稳落地。
- 原理是中学物理，难点是工程：控制算法、传感器融合、阀门响应、结构强度、安全冗余。

# 要点：知识储备与入门

## 知识量大，但不是一个人掌握全部

- 这辆车背后是特斯拉 + SpaceX 上千名工程师，每人精通一块。
- 火箭、无人机、飞机、机器人共用同一组底层知识：

| 底层知识 | 用在哪里 |
|---|---|
| 力学（牛顿定律、动量） | 火箭推进、冷气推进器 |
| 流体力学（压差、升力） | 飞机机翼、吸附风扇 |
| 控制理论（反馈、PID） | 无人机悬停、机器人平衡、空中翻滚 |
| 嵌入式 + 软件（传感器、电机驱动、实时代码） | 全部四类 |

- 已有基础：flight-deck 项目（MSFS + ESP32）已经接触飞行动力学和嵌入式两块。

## 入门路线（从便宜、能动手的开始，后一步复用前一步）

1. **自组四轴无人机**：ESP32 或开源飞控（Betaflight / ArduPilot）。PID、传感器融合在这一步学会，性价比最高。
2. **两轮自平衡小车**：控制原理同无人机，炸机成本更低，衔接机器人方向。
3. **水火箭 → 合规模型火箭**：先用 OpenRocket 仿真，再发射，验证推力和稳定性。
4. 配套读物：《控制之美》（控制入门）；NASA *Beginner's Guide to Aeronautics*（免费，飞行与火箭原理）。
