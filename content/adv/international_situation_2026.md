# 要点

## 全球经济：IMF 2026-07 展望

| 项目 | 预测 |
|---|---|
| 全球增长 | 下调至约 3% |
| 发达经济体 | 约 1.7% |
| 新兴市场和发展中经济体 | 约 3.8% |
| 中国 | 上调至约 4.6% |
| 全球通胀 | 约 4.7% |
| 全球贸易量增速 | 约 3.5% |

下调主因：中东战事推高能源价格、关税与贸易不确定性。

## 中美关系：竞争为主，有限合作

- 特朗普第二任期关税战延续。
- 2026-02 美国最高法院裁定依据 IEEPA 加征的关税违法，政府改用 122 条款（国际收支）、232 条款（国家安全）、301 条款（不公平贸易）继续加税。
- 2026-05 特朗普访华（具体成果待查）。
- 2026 年中国主办 APEC，美国主办 G20，多边场合互动频繁。
- 大方向：科技、产业链上的结构性竞争长期存在；贸易、气候等领域有限合作。

## 中东：美以伊冲突

- 2026-02-28 开战；霍尔木兹海峡多次封锁又恢复通航。
- 油价剧烈波动，停火多次破裂。
- 影响：全球能源价格与通胀上升；中国作为原油进口大国，加快能源多元化和新能源替代。

## 俄乌冲突

- 2026-09 美国特使威特科夫、库什纳在莫斯科、基辅之间斡旋。
- 特朗普政府希望在 11-03 中期选举前拿出外交成果。
- 目前讨论的是冬季局部降级（例如互不攻击能源设施），全面停火仍难。

## 几个大趋势

1. **地缘政治碎片化**：阵营化、供应链「友岸化」「去风险」。
2. **经济安全化**：关税、出口管制、产业补贴成为常规政策工具，各国都在把「安全」放到「效率」前面。
3. **AI 与科技竞争**：芯片、大模型、算力成为大国竞争核心。
4. **能源转型与能源安全并行**：一边推新能源，一边战争推高油气价格。
5. **全球南方地位上升**：金砖扩员、「一带一路」、新兴市场增长高于发达经济体。

## 国际形势怎样传到国内政策

| 外部变化 | 国内政策回应 |
|---|---|
| 关税、出口管制 | 扩大内需（内需主导）、全国统一大市场、市场多元化 |
| 芯片、技术封锁 | 科技自立自强、集成电路重点培育、新型举国体制 |
| 能源价格波动 | 新型电力系统、新能源、能源资源基地（新疆定位） |
| 全球增长放缓 | 更积极的财政政策（赤字率约 4%、超长期特别国债） |
| 地缘冲突 | 统筹发展和安全、守牢底线 |
