# 要点

## 一、经济学的三个基础问题

1. 社会应该**生产什么**？
2. 应该**如何生产**？
3. **谁来消费**所生产的东西？

这三个问题是每种经济制度、每个社会的基础。无论是社会主义还是共产主义社会，也无论是低收入、中等收入还是高收入国家，都要回答。

各种回答可以排成一条光谱：一端是政府完全管制，由政府机关决定生产什么、怎么生产、谁来消费；另一端是由市场决定（另一端的原文在图外，按上下文推断）。

## 二、机会成本

- **所有成本都是机会成本**：做一个选择时，你没有选的那个选项就是机会成本。
- 例：雇人打扫房子，每次 150 美元，每月两次，一年 3600 美元，相当于去海边度假一周。真正的成本不是花掉的钱，而是放弃的东西。
- 例：全职大学生放弃了工作赚钱的时间，这也是上大学的成本之一。
- 用机会成本思考，就会把那些没有用钱衡量的成本也算进去。

## 三、价格由市场决定，而不是生产者

- 油价上涨时，人们骂石油公司；油价下跌时，没人夸石油公司慷慨。利率也一样。
- 这些褒贬都建立在一个错误假设上，就是价格由生产者说了算。
- 政策思路：想让某样东西少一点就收税抑制，想让它多一点就补贴鼓励。个别选择可能聪明也可能不明智，但至少是在引导，而不是无视问题。

## 四、循环流向图（第 03 章）

```
          ┌─ 商品与服务市场：厂商 → 商品服务 → 家庭；家庭 → 支出 → 厂商
家庭 ⇄ 厂商 ├─ 劳动力市场：    家庭 → 劳动力 → 厂商；厂商 → 工资报酬 → 家庭
          └─ 资本市场：      家庭 → 资本   → 厂商；厂商 → 利息/股利 → 家庭
```

- **劳动力市场**：供需角色和商品市场相反，厂商需要劳动，家庭供给劳动。书中举例：塔吉特百货（Target）约 35 万员工，公司以工资和福利付费给工人及其家庭。
- **资本市场**：家庭把钱直接买股票，或存进银行，这些钱再投资或借给厂商，家庭收到股利和利息。所以家庭是资本的供给者，厂商是需求者。厂商也可能供应资金，但它是代表业主或股东投资，最终供给者仍是家庭。
